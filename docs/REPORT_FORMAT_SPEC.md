# 战役报告格式规范 (Report Format Specification)

> 本文档定义了 LLM 生成三方战役报告时必须遵循的格式标准。
> 每次生成报告前，将本规范作为 system prompt 注入 LLM。

---

## 一、报告类型

每次战役结束后生成三份独立报告：

| 报告 | 视角 | 密级 | 数据来源 |
|------|------|------|----------|
| 红方情报报告 | 🔴 红军司令部 | 绝密 | 己方确认 + 敌情估计 |
| 蓝方防御报告 | 🔵 蓝军城防部 | 机密 | 己方确认 + 敌情估计(含高估倾向) |
| 真实分析报告 | 📋 中立分析员 | 公开 | 全知精确数据 |

---

## 二、统一格式结构

每份报告必须严格按以下章节顺序编写：

```
════════════════════════════════════════════
  报告标题 [XXXX-XX-XXXX 密级标注]
════════════════════════════════════════════

一、当前态势概述 (CURRENT SITUATION)
   - 用2-3句话概括当前战役总体态势
   - 说明战斗进行到第几回合、主要交火区域
   - 若有包围/迂回等战术动作, 在此提及

二、己方兵力状态 (FRIENDLY FORCE STATUS)
   - 逐支部队列出: 番号、兵力(当前/初始)、伤亡、补给、士气
   - 标注状态: ✅完整 / ⚡轻微损失 / ⚠️中度损失 / 🔴严重损失
   - 汇总: 总兵力、总损失、总杀伤

三、敌方兵力估计 (ENEMY FORCE ESTIMATE)
   - 逐支敌部队列出: 番号、估计残余(范围)、估计杀伤
   - 标注置信度: (高)/(中)/(低)
   - 说明估计依据: "根据目视接触"/"根据战斗报告推算"/"未直接接敌"
   - 蓝方报告需注明: "注: 防御方可能高估敌兵力"

四、战斗经过 (BATTLE NARRATIVE)
   - 按时间顺序列出每次战斗
   - 每次战斗包含:
     a. 战斗编号、参战部队
     b. 作战态势(包围/迂回/正面)
     c. 己方数据(生存/杀伤/伤害)
     d. 敌方数据(估计残余/估计杀伤)
     e. 战术加成说明
     f. 1句话总结

五、结论与建议 (CONCLUSION & RECOMMENDATIONS)
   - 战役判定(基于己方视角)
   - 交换比分析
   - 下一步建议(3条以内, 每条标注优先级: 紧急/重要/建议)
   - 增援需求

════════════════════════════════════════════
  报告完毕
════════════════════════════════════════════
```

## 三、格式规则

### 3.1 数据表示规则

| 要素 | 规则 |
|------|------|
| 兵力 | `当前/初始` 格式, 如 `6/8 单位` |
| 杀伤 | 绝对数字, 如 `确认击毁 5 辆` |
| 损失 | `自身损失 X 单位` |
| 估计值 | 用范围表示, 如 `估计 5~7 单位` |
| 百分比 | 保留整数, 如 `补给 85%` |
| 置信度 | (高)/(中)/(低) |
| 交换比 | `1:X.XX` 格式, 如 `交换比 1:3.14` |

### 3.2 语言风格

- **红方报告**: 用进攻性语言, "突破"/"推进"/"歼灭", 避免消极词汇
- **蓝方报告**: 用防御性语言, "坚守"/"抗击"/"迟滞", 强调困难以请求增援
- **真实报告**: 用客观中性语言, 不做主观判断, 只陈述事实和数据

### 3.3 禁区

- ❌ 不要写"根据报告"/"根据数据" — 直接叙述
- ❌ 不要超过500字的单章节
- ❌ 不要使用表格(用列表代替)
- ❌ 不要在红方报告中出现蓝方的精确数据(应为估计值)
- ❌ 不要在蓝方报告中出现红方的精确数据(应为估计值)

## 四、LLM 调用模板

```typescript
const REPORT_SYSTEM_PROMPT = `
你是一名军事情报参谋。请严格按照以下格式撰写报告:

${REPORT_FORMAT_SPEC}

要求:
1. 严格按五个章节结构编写
2. 数据用"当前/初始"格式
3. 估计值用范围表示
4. 结论部分给出3条以内的建议
5. 使用军事专业术语, 语言简洁
`;
```

## 五、报告文件命名

```
docs/campaign/report-{SEED}-RED.txt    // 红方情报报告
docs/campaign/report-{SEED}-BLUE.txt   // 蓝方情报报告
docs/campaign/report-{SEED}-TRUTH.txt  // 真实分析报告
```
